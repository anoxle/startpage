## 💡 About

A minimal, highly customizable startpage.

### ✨ Features
#### 🎨 **Full Visual Customization:** Tweak everything you see in the site:
  * **Fine-Tuned Slider Controls:** Freely adjust sizes, padding, rounding with sliders on all widgets.
  * **Widget Presets:** Switch between 5 pre-built design presets for each widget.
  * **Visual Editor:** Drag, drop, and place any element freely anywhere on your screen.
  * **Customizable Background:** Set any image or video as a background with built-in blur and darkness controls.
  * **Site-Wide Color Themes:** Pick from 5 built-in color schemes or build a completely custom palette.

#### ⚡ **Power Features:** Everything you need for a fast workflow:
  * **Custom Site Shortcuts:** Type `@key` in the search bar to search specific sites instantly (e.g., `@gpt hello`, `@yt cats`).
  * **Engine Switching:** Easily switch between 4 default search engines or set a custom search provider.
  * **Quick Links:** Organize your favourite sites with custom layouts.
  * **Transfer Settings:** Export and import your complete layout and settings instantly via a single JSON file.

#### 🔒 **Privacy & Performance:** Built to be fast, lightweight, and private:
  * **Local-First Storage:** All your data, layouts, and custom settings stay **100%** inside your browser (`localStorage`).
  * **Fast Load Times:** Lightweight build with zero heavy dependencies for a fast new tab load.
  * **Zero Analytics:** No tracking, no external databases, and zero data collection.

## 🚀 Usage

To set this as your default new tab page, install one of the recommended extensions and point it to the live URL.

**Live URL:** [https://anoxle.github.io/startpage/](https://anoxle.github.io/startpage/)

### 🔌 Extensions

- **Chrome / Brave / Edge / etc:** Use [New Tab Redirect](https://chromewebstore.google.com/detail/new-tab-redirect/icpgjfneehieebagbmdbhnlpiopdcmna)
- **Firefox / Zen / Waterfox / etc:** Use [New Tab Override](https://addons.mozilla.org/en-US/firefox/addon/new-tab-override/)

> ⚠️ **Note on Opera / Opera GX / Comet:**  ⚠️  
> Extensions listed above may not work on these browsers. Third-party extensions or other solutions may be required.
